# 캐릭터 아트 넣는 곳

이 폴더에 캐릭터 이미지 파일을 넣고, `server.js`의 캐릭터 설정에 `image` 경로만 지정하면
기본 SVG 마스코트 대신 그 이미지가 아바타로 사용됩니다.

## 사용법

1. 이미지 파일을 이 폴더에 넣습니다. 예: `public/characters/kongi.png`
   - 권장: 정사각형(예: 512×512), 배경 투명 PNG (히어로·카드·목록·채팅 어디서든 깔끔하게 보임)
2. `server.js`의 해당 캐릭터에 `image` 필드를 추가합니다.

   ```js
   kongi: {
     name: "콩이",
     // ...기존 필드...
     image: "/characters/kongi.png",   // ← 이 줄만 추가하면 이미지로 교체됨
   },
   ```
3. 서버를 다시 시작하면 바로 반영됩니다. `image`가 없으면 기존 SVG 마스코트를 그대로 씁니다.

## 주의 (중요)

- 여기에 넣는 이미지는 **여러분이 사용 권리를 가진 아트**여야 합니다.
  타사 저작권/상표가 있는 캐릭터(예: 애니메이션 IP)는 **정식 라이선스를 확보한 뒤에만** 사용하세요.
- 이 구조는 "라이선스한 아트를 그대로 꽂으면 동작하는" 것을 목적으로 합니다.
  즉, IP사와 계약 후 공식 아트를 이 폴더에 넣으면 코드 수정 없이 캐릭터가 교체됩니다.
