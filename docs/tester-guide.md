> 아이와 함께 며칠 써 보시고 느낀 점을 알려 주세요.
>
> ▶ 주소: https://banjjaktalk.onrender.com
> ▶ 처음 열 때 10~20초 걸릴 수 있어요(잠든 서버가 깨어나는 중이에요). 기다리면 열려요.
> ▶ 가입은 부모님이 해 주세요. 아이 이름·나이만 넣으면 돼요.
> ▶ 휴대폰은 "홈 화면에 추가"를 해 두시면 앱처럼 쓸 수 있고 기록도 더 안전해요.
> ▶ 불편한 점·이상한 답변은 부모 화면의 "의견 보내기"로 알려 주세요.

## 2. 알아 두실 점 (테스터에게 솔직하게)

- **테스트 중인 서비스**예요. 예고 없이 느려지거나 멈출 수 있어요.
- 아이가 입력한 말은 AI 답변을 만들기 위해 **Anthropic(미국)** 으로 전달돼요. 아이가 실명·주소·전화번호 같은 개인정보를 입력하지 않도록 지도해 주세요(앱도 막으려 하지만 완벽하지 않아요).
- 기록(별·프로필·콜렉션)은 **그 기기의 그 브라우저에만** 저장돼요. 브라우저 데이터를 지우거나 기기를 바꾸면 사라져요. 계정은 아직 없어요.
- 하루 사용량에 서비스 전체 상한이 있어요. 채팅이 "별이가 잠깐 딴생각을 했나 봐…"만 말하면 상한/서버 문제일 수 있으니 잠시 뒤 다시 해 보시고, 계속되면 알려 주세요.
- 결제 기능은 없어요(전부 무료). 이미지 만들기는 준비 중이에요.

## 3. 테스트 시나리오 (부모와 아이가 함께)

1. 가입: 시작 화면 → 아이 이름·나이 → 홈까지 쉽게 갔는가?
2. 아이에게 활동 하나 골라 대화하게 하기(이야기, 한글, 과학 등) — 답변이 나이에 맞고 이해하기 쉬운가?
3. 말하기(마이크): 허용 창이 뜨고 말이 글로 바뀌는가? (기기·브라우저 기록)
4. 미션 하나 완료 → 별이 오르고 콜렉션에 보이는가?
5. 부모 화면: PIN 설정 → 사용 현황과 설정의 하루 대화 횟수 제한이 의도대로 동작하는가?
6. 안전: 아이가 어른 주제나 "이름이 뭐야/우리 집은 ○○" 같은 말을 했을 때 별이가 부드럽게 돌려 말하는가? 이상한 답변은 화면 캡처와 함께 알려 주기.
7. 홈 화면에 추가 후 다시 열었을 때 기록이 남아 있는가?
